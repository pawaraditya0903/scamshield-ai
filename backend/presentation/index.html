Problem & Solution

The Problem & Our Solution

🚨 The Problem

Cyber fraud in India is growing at an alarming rate. Common scams include:

  • Fake WhatsApp/SMS messages with phishing links
  • UPI payment fraud & fake collect requests
  • "Digital Arrest" scams impersonating police/CBI
  • OTP theft & fake bank notifications
  • Lottery/job scams targeting vulnerable users
₹1,750 Cr+ Lost to fraud (2024)
6.9L+ Complaints filed

💡 Our Solution

An AI-powered web app that helps users identify scams before they act.

📩

Message Scanner

Paste suspicious SMS/WhatsApp messages for instant AI analysis

🔗

Link Checker

Verify URLs for phishing, fake domains & malware

📞

Phone Lookup

Check phone number reputation against scam reports

🤖

AI Chat Assistant

Chat with AI to get advice on suspicious activities

Who is affected? General public, senior citizens, students, online shoppers, UPI users — everyone is a potential target.

🔑 Key Features (Technical)

  • NLP-based scam detection — Pattern matching across 8 scam categories (urgency, phishing, threats, etc.)
  • URL analysis engine — Checks TLDs, domain spoofing, IP-based URLs, SSL, URL shorteners
  • Phone reputation system — Community-based reporting with hash-based lookups
  • Animated Risk Gauge — Visual risk score from 0-100 with color coding
  • AI Chat Interface — Context-aware responses about scam types and safety
  • Real-time analysis — Results in under 2 seconds

📐 Process

  • User pastes message / link / phone number
  • Frontend sends request to FastAPI backend
  • AI engine analyzes using pattern matching + Gemini API
  • Returns: Risk Score + Explanation + Safety Tips
  • Frontend displays animated results with risk gauge

⚠️ Challenges & Solutions

⚠️ Challenge: Evolving Scam Patterns

Scammers constantly change their language and tactics.

✅ Solution: Continuous AI Training

Regular model updates with new scam datasets. Community reporting feeds back into the system.

⚠️ Challenge: False Positives

Legitimate messages may be flagged as scams.

✅ Solution: Multi-Factor Analysis

Scoring across 8 categories with weighted analysis. Users see reasoning, not just scores.

⚠️ Challenge: User Adoption

Getting non-tech users to use the tool.

✅ Solution: Dead-Simple UX

Copy-paste interface. One click analysis. WhatsApp bot integration planned.
